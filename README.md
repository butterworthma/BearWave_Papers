# BearWave Papers

This repository collects the publication material for the BearWave project.

## Contents

- `Paper 1/` - original BearWave paper repository, previously held in `butterworthma/BearWave`.
- `Paper 2/` - second BearWave paper repository, previously held in `butterworthma/BearWave-Paper2`.
- `Paper 3/` - current Paper 3 source, including the SSTV/image-transfer updates and revised figures.

The papers are kept together here so the research narrative, figures, source data, and LaTeX material can be maintained as one publication archive.
