# Paper 2 data

For the current manuscript, start with the [reproduction guide](reconstructed_trials_2026-10-05/reproducibility_2026-10-06/README.txt) and [analysis protocol](reconstructed_trials_2026-10-05/reproducibility_2026-10-06/ANALYSIS_PROTOCOL_v1.3.txt).

- [Separate reception windows](reconstructed_trials_2026-10-05/test_index.csv): W1–W7 data, descriptive summaries and reception intervals.
- [Current analysis inputs](reconstructed_trials_2026-10-05/reproducibility_2026-10-06/inputs): reception inventory, window/configuration rules, ionosonde series, map pixels and Pi diagnostic output.
- [Recomputed results](reconstructed_trials_2026-10-05/reproducibility_2026-10-06/results): complete numerical outputs and validation report.
- [Field documentation](../field_documentation/README.md): trial plan, chronology, equipment and photographs.

The other spreadsheets and preview CSV in this directory are earlier analysis material. Their filenames are preserved, including the historical `5_GHZ_...` label: the relevant radio band is approximately **5 MHz**, not 5 GHz. The current analysis assigns exact frequency from receiver tuning records.

These data are tracked in this repository. The original source workbooks/maps and raw radio-message archive are not all redistributed; the reproduction guide explains the included numerical inputs and source boundaries.
